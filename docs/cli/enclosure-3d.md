# 3D 外壳设计(待支持阶段)

> **状态:🚧 规划中,未实现。** 本文是功能规划占位——定义目标能力与数据基础,
> 不描述任何现有命令。实现排期见 [`docs/ROADMAP.md`](../ROADMAP.md)。

## 目标

板子设计完成后,从**已有的板级数据**直接生成可打印/可加工的外壳模型——AI agent
一条链路走完「原理图 → PCB → 外壳」,不再手工量尺寸建模。

## 规划能力

| 能力 | 输入(已有数据) | 产出 |
|---|---|---|
| 外壳生成 | `pcb.outline.get` 真板框多边形 + 板厚/叠层 | 参数化外壳模型(OpenSCAD/STEP),内腔贴合板框+公差 |
| 安装孔对齐 | 板上 M3 等安装孔坐标(pcb list) | 壳底螺柱/沉孔与板孔同心 |
| 接口开孔 | 块库**插拔件 openings 声明**(`_connector_openings.json`:开口方向/尺寸)+ 插头包络表(`_plug_envelope.json`:depth/overhang) | 壳壁上 USB/端子/SD 等开孔,含插头护套让位 |
| 按键/LED 透窗 | 器件坐标 + 高度(块 placement/封装数据) | 按键顶杆孔、LED 导光窗 |
| 净空校验 | 器件 3D 高度包络 | 壳内高度干涉检查(报告,不静默) |

## 数据基础(为什么可行)

外壳所需的每类几何**已在现有数据链路里**:

- 板框真多边形:`pcb.outline.get` 返回铣刀路径中心线(`points` + `outlineFormat`),异形板不按 AABB 错算;
- 插拔件开口:块库已带 `openings` 声明(六板实测反推)与插头包络 depth/overhang 字段——PCB 侧的插拔通道禁布(mating corridor)用的就是同一份数据,外壳开孔是它的第三个消费者;
- 安装孔/器件坐标:`pcb list --include-bbox --include-pads`。

缺口是**器件 3D 高度**(平台 3D 模型 API 可达性未探测)与**建模输出管线**(OpenSCAD
代码生成 vs 平台 3D 导出),这两项是立项时的首批调研题。

## 验收方向(立项时细化)

- 固定回归板(ESP32-S3)一键出壳:USB 口对孔可插、四角 M3 对位、按键可按、一次打印装配成功;
- 开孔位置全部来自数据推导,零手工量尺寸;
- 干涉检查报告与 PCB 侧 check 同风格(逐项 finding,非布尔)。
